# HouseLoadCalculator Ver.1.2

一般住宅用の負荷計算書PWAです。

## ファイル構成

フォルダなしのフラット構成です。

- index.html
- style.css
- app.js
- manifest.json
- service-worker.js
- icon-180.svg
- icon-192.svg
- icon-512.svg
- README.md

## 主な機能

- 照明・コンセント負荷計算
- 専用負荷計算
- 需要率計算
- 推奨契約容量
- 推奨主幹
- 幹線サイズ参考選定
- 分岐回路数参考表示
- 分電盤候補参考表示
- 電力会社申請用の印刷レイアウト
- JSON保存・読込
- PWA対応
- 更新通知・キャッシュ自動更新
